# 外観パースづくり 手順書（Codex アプリ・Windows）

各棟の外観パース（PDF）から、何棟も並んだ写真風の外観パースを AI（Codex）に作ってもらう手順です。直したい所は1か所ずつ直すので、ChatGPT のように「直すとほかの所が変わる」ことが起きにくくなります。

## 1. 最初に1回だけ

1. Notion の `外観パーステンプレート.zip` をダウンロードする
2. zip を右クリック →「すべて展開」→ できた `外観パーステンプレート` フォルダを「ドキュメント」に移す
3. スタートメニューで **PowerShell** を開き、次の2行を1行ずつ貼って Enter（1〜2分かかる）

```
cd "$HOME\Documents\外観パーステンプレート\tools"
```
```
uv venv --python 3.13 .venv; uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

   `uv` が見つからないと出たら、販売図面テンプレートのときの準備（uv を入れる1行）が済んでいないので、その画面を小暮に送ってください

## 2. 物件ごとに

1. 「ドキュメント」に `外観パース` フォルダを作り、その中に `20261023_朝霞市膝折町4丁目` のような **日付_物件名** のフォルダを作る
2. その中に `資料` フォルダを作り、次を入れる
   - 各棟の外観パースの PDF（1棟1ファイル）
   - 区画図と間取り図が載った販売図面の PDF（並び順と車の向きを読むため）

## 3. Codex アプリで作る

1. Codex アプリで **プロジェクトを開く** →「ドキュメント › 外観パーステンプレート」を選ぶ
2. 次の文を貼って送る（物件フォルダ名と説明は自分のものに直す）

```
このフォルダの AGENTS.md の手順で、外観パースを作ってください。
物件フォルダは ドキュメント\外観パース\20261023_朝霞市膝折町4丁目 で、資料は「資料」フォルダに入れてあります。
全5棟で、看板（横150×縦90cm）に使います。
Python は tools\.venv\Scripts\python.exe を使ってください。
まず各棟の外観と並び順・車の向きを読み取って、確認させてください。
```

3. Codex が各棟の特徴と並び順・車の向きをまとめて見せてくるので、合っているか答える
4. 1枚目ができたら、Codex が棟ごとに元のパースと違う所を挙げてくる。直したい所を伝える

## 4. 直してもらうときの頼み方

- **1回に1か所** 頼む。例:「4号棟の右側の屋根を切妻にして」
- 場所は「◯号棟の◯◯」で伝える。画像に赤や緑で印を付けて渡してもよい
- 色は「もっと白く」「グレーに」のように言えば、その壁だけ直す
- 気に入らなければ「1つ前の版に戻して」と言えば戻せる（前の版は消えない）
- 夕方版がほしいときは、「夕方版も作って」と、参考の写真があれば一緒に渡す

## 5. できあがり

- 画像は物件フォルダの `out` に入る。看板用は `final_` で始まるファイル
- 看板に使うときは、前にお伝えした Upscayl で **6倍** にしてから印刷会社に渡す
- キャッチコピーは画像に入れていないので、Canva や PowerPoint で載せる
- LINE で画像を送ると画質が落ちるので、看板用の画像は zip にしてファイルで送る

## 6. うまくいかないとき

- 「usage limit」と出たら、画像を作れる回数の上限です。表示された時刻を過ぎてから、もう一度頼んでください
- それ以外のエラーは、Codex の画面の文をそのままコピーして小暮に送ってください

## 7. 注意

- 資料と出来上がった画像は「ドキュメント › 外観パース」に置き、このフォルダ（外観パーステンプレート）の中には入れない
- 車の向きや並び順は、AI が間違えやすい所です。出来上がりで必ず確かめてください
