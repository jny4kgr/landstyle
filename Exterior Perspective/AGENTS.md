# 外観パースを作る AI エージェントへの指示（Codex / Claude Code 共通）

このフォルダで作業する AI エージェントは、営業担当者と対話しながら、分譲地の外観パース（複数棟が並んだ写真風の1枚。看板・チラシ用）を作る。画像は Codex の組み込み画像生成（image_gen）で作り、直しは **1か所ずつ切り出して編集し、元の画像に貼り戻す**。

ChatGPT に会話で修正を重ねると、直したい所以外まで変わってしまう。画像生成は、指示のたびに1枚を丸ごと描き直すからだ。この手順は、それを防ぐためにある。

## 1. 守ること（例外なし）

1. **参照画像は1回に5枚まで。** 6枚以上渡すと生成が止まる。棟が6棟以上なら、営業に相談して2回に分ける
2. **画像に文字を入れない。** キャッチコピーは、営業が後から Canva や PowerPoint で載せる。文字が入っていると、修正のたびに崩れる
3. **1回の編集で直すのは1か所だけ。** 指示文には必ず「変えないもの」を書く。消して描き足すような直しは「消す」「足す」の2回に分ける
4. **全体を作り直さない。** 最初の生成のあとは、部分修正（4章）だけで直す。例外は時間帯の変更（5章）だけ
5. **前の版を上書きしない。** `out/v1.png`、`out/v2.png` … と番号を進め、何を直したかを `修正履歴.md` に1行ずつ書く
6. **形を推測で決めない。** 屋根・窓・バルコニー・駐車の向きは、資料（各棟の外観パース・区画図・間取り図）に合わせる。資料で分からないことは営業に聞く
7. **実物件の資料と画像をこのリポジトリに入れない。** 物件フォルダはリポジトリの外に置く（2章）。commit・push は指示があるときだけ

## 2. 物件フォルダ

リポジトリの外に、1物件1フォルダで作る。

```
ドキュメント/外観パース/<YYYYMMDD>_<物件名>/
├── 資料/        営業から受け取った PDF（各棟の外観パース、区画図・間取り図の載った販売図面）
├── 参照/        資料を PNG にしたもの（手順 1 で作る）
├── edit/        部分修正の作業ファイル（切り出し・編集結果）
├── out/         版ごとの画像（v1.png, v2.png …）と仕上げ（final_*.png）
└── 修正履歴.md   版ごとの「営業からの依頼／直した所／ファイル名」
```

## 3. 最初の1枚を作る

スクリプトは `tools/` にある。以下、`$T` は `Exterior Perspective/tools`、`$P` は物件フォルダ。Python は依存を入れた環境（`tools/requirements.txt`）で実行する。

### 手順 1: 資料を PNG にする
```bash
python $T/pdf_to_png.py $P/資料 $P/参照
```

### 手順 2: 資料を読み、営業に確認する
- 各棟の外観パースを見て、棟ごとに1行で「外壁の色・屋根の形（切妻／片流れ／寄棟）・2階のバルコニー（有無・幅・突き出すか）・窓の数・外壁の貼り分け」を書き出す
- 区画図・間取り図から、棟の並び順、各棟の駐車の向き（間取り図に描かれた車の向き）、転回広場などの道路の形を読む
- 書き出した内容を営業に見せて、**並び順（手前から何号棟か）と駐車の向きだけは必ず確認する**。過去に「並列」「縦列」という言葉が、間取り図の車の向きと逆の意味で使われていたことがある。言葉ではなく、間取り図の車の描き方で確かめる

### 手順 3: 生成する
- 「指示文の雛形 A」（6章）を埋め、各棟の PNG（5枚まで）を参照画像として、image_gen を **1回** 呼ぶ。サイズは横長 1536x1024
- 結果を `$P/out/v1.png` に保存する

### 手順 4: 1棟ずつ照合する
- 生成画像の各棟を拡大し、参照画像と並べて、手順 2 の1行メモと一つずつ照らす
- 違いを箇条書きで営業に見せ、直す順番を決めてもらう。違いが無い所まで「直しましょうか」と聞かない

## 4. 部分修正（1か所ずつ）

### 手順 5: 直す場所を切り出す
```bash
python $T/crop_for_edit.py --image $P/out/v1.png --box x0,y0,x1,y1 --out $P/edit/<名前>_in.png
```
- `--box` は直したい物を囲む矩形（元画像の座標）。周りの壁や地面が少し入るくらいに取る。スクリプトが 3:2 に広げて 1536x1024 にする

### 手順 6: 1か所だけ編集する
- 「指示文の雛形 B」（6章）で、`<名前>_in.png` を編集対象として image_gen を1回呼ぶ。結果を `$P/edit/<名前>_out.png` に保存する
- 結果を見て、直した所が狙いどおりか確かめる。違えば、その結果を新しい編集対象にして、違う点だけをもう一度直す

### 手順 7: 元の画像に貼り戻す
```bash
python $T/paste_back.py --base $P/out/v1.png --edited $P/edit/<名前>_out.png --meta $P/edit/<名前>_in.png.json --rect x0,y0,x1,y1 --out $P/out/v2.png
```
- `--rect` は、編集結果（1536x1024）の中で **直した物がある範囲**。ここだけが貼り戻され、外側は元の画像のまま残る。省略すると差分から自動で決めるが、関係ない所まで拾うことがあるので、なるべく指定する
- `--rect` は **直す前の物と直した後の物の両方** を囲み、さらに四辺に 40px 以上の余白を取る。境目をぼかすため、矩形の縁から約 30px 内側までは元の画像が混ざる。余白が足りないと、前の物（例: 向きを変える前の車の屋根）が薄く消え残る
- 「上端の平均差」が 20 を超えたら、編集で画角がずれている。貼り戻した境目を拡大して確かめる
- 貼り戻した所を拡大して、継ぎ目・前の物の消え残り（薄い影）が無いか確かめる

### 直すときのコツ（実際につまずいた所）
- **車の向き**: 「横向き・車の前が右」だけだと、真横から見た水平な車になり、家に対して斜めに見える。「前輪と後輪を結ぶ線が、手前の縁石や駐車場の目地の線と同じ傾き」と書く
- **車を奥に下げる**: 一度で頼むと、車が柱で縦に切れた不自然な絵になりやすい。「車を消す」→「車の前の部分を描き足す」の2回に分ける
- **小さい物（砂利の帯・植栽）**: 1536 の画像の中で数ピクセルの太さだと、看板では見えない。「奥行き約1m」「白い車のヘッドライトの高さくらいの幅」のように、画像の中の物を基準に大きさを書く
- **色**: 「もう少し白く」「グレーに」は、壁の範囲だけを切り出して直す。営業の言う色は途中で変わることがあるので、前の版は消さない

## 5. 時間帯を変える（夕方版など）

- 全体の光が変わるので、例外として画像全体を編集する。「指示文の雛形 C」（6章）で、仕上がった版を編集対象、営業の参考写真（あれば）を2枚目にして、image_gen を1回呼ぶ
- 形が変わっていないかを確かめる:
```bash
python $T/check_overlay.py --a $P/out/v8.png --b $P/out/夕方.png --out $P/edit/夕方_重ね.png
```
- 重ね画像で、元の輪郭が赤、新しい輪郭が緑、一致した所が黄色になる。建物・窓・車がほぼ黄色なら合格。赤と緑がずれている棟があれば、その棟を4章の手順で直す
- 表示される輪郭一致率（許容 2px）は目安。形が保たれた夕方版で 96%、まったく別の画像でも 80% 前後出る（濡れた路面や植栽の細かい輪郭が偶然重なるため）。90% 未満なら必ず棟ごとに確かめ、90% 以上でも最後は重ね画像を目で見て決める

## 6. 指示文の雛形

### 雛形 A（最初の生成）
```
新築分譲地（全◯棟）の外観パースを、写真のようにリアルな1枚の画像にしてください。

【添付画像の役割】
・画像1〜◯：1号棟〜◯号棟の外観パース。建物の形・屋根・窓の数と位置・バルコニー・外壁の貼り分けは、この画像に正確に合わせる（ここが最優先）

【構図】
・横長（3:2）。道路の右手前に立って、人の目の高さから斜めに見たアングル。手前の1号棟が大きく、奥に行くほど小さくなる遠近感
・並び順は、右手前から 1号棟 → 2号棟 → …（一番左奥が◯号棟）
・各棟の前に駐車スペースと車、植栽。手前は道路
・青空と白い雲、明るい昼の日差し。画面の上3分の1は空にして、建物や木を入れない（後で文字を載せるため）

【各棟の外観（画像のとおり）】
・1号棟（画像1）：外壁は◯◯。◯◯屋根（黒）。2階の◯◯に◯◯のバルコニー。…
・2号棟（画像2）：…

【駐車】
・1号棟：道路と平行な横向き、車の前は画面の右。…
・3号棟：建物の左側に、道路に対して縦向き。建物の前は道路（転回広場）

【変えない・入れないもの】
・文字・ロゴ・看板は一切入れない
・郵便ポストや機能門柱は置かない
・窓を増やしたり減らしたりしない。バルコニーを足したり消したりしない
```

### 雛形 B（部分修正）
```
この画像は、住宅が並ぶ写真の一部を切り出したものです。◯◯だけを直してください。

【直すところ（1か所だけ）】
・（何を、どう変えるか。向き・大きさ・位置は、画像の中の物を基準に書く）

【変えないもの】
・（直す物以外の家・車・植栽・道路・空）は、ピクセル単位でできるだけ元のまま
・画角・拡大率・構図を変えない。文字は入れない
```

### 雛形 C（時間帯の変更）
```
画像1の住宅地の写真を、同じ場所・同じ瞬間の「夕方（日没直後のマジックアワー）」の写真に変えてください。変えるのは時間帯と光だけです。

【変えるもの（光と色だけ）】
・空：夕焼け。上はくすんだ青紫、地平線に近いほどオレンジ〜ピンクの雲（雰囲気は画像2と同じ）
・建物：全体に少し暗くなり、夕日の暖かい色が当たる。すべての窓に室内の暖かい明かりが灯る
・植栽：木の根元からのアップライトで、葉が下から暖かく照らされる
・道路：濡れたアスファルトに、窓の明かりや照明の暖かい光が映り込む
・車：ボディに夕焼けの映り込み。ライトは点けない

【変えないもの（最優先）】
・建物の形・屋根・窓の数と位置・バルコニー・外壁の貼り分け・外壁の色の違いは、画像1とピクセル単位で同じ位置・同じ形のまま
・車の台数・位置・向き、植栽の位置、道路の形もそのまま
・画角・構図・拡大率を変えない。物を足したり消したりしない
・文字は入れない
```

## 7. 仕上げ

```bash
python $T/finish.py --image $P/out/v8.png --out $P/out/final_昼.png --ratio 5:3 --sign 150x90 --dpi 150
```
- 看板の比率で切り出す（下の道路側から削る）。表示される倍率で、営業が Upscayl（無料の高画質化ソフト）にかける。150x90cm・150dpi なら、1460x876 の画像は 6 倍でほぼ足りる
- 画像を LINE で送ると圧縮される。看板用の元画像は zip にしてファイルで渡す

## 8. 画像生成の回数の上限

image_gen には利用上限がある。上限に達すると「usage limit」と出て、表示された時刻まで生成できない。その間に、照合・貼り戻し・仕上げ（スクリプトだけで済む作業）を進める。
