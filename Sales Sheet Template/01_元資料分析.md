## 2. レイアウト構造

### 型 A　自社 Excel 型（③マンション・⑤土地）

3列＋帯。Excel 方眼紙の結合セルで枠を作り、写真・図・地図を画像で貼っている。

```
+----------------------+--------------------------+---------------------------+
| 外観写真（③）          | [黒帯] Room Layout（③）   | [物件の要約表]              |
|   撮影日キャプション     |        Division（⑤）     |  物件名称／種目（⑤）         |
| or 種目＋所在地見出し（⑤）|  間取り図 or 区画図        |  交通／間取り／販売価格       |
+----------------------+   ＋図の注記               |  所在地                    |
| ◆☆ セールスポイント 4〜5行 |                          +---------------------------+
+----------------------+--------------------------+ [物件スペック表]             |
| [黒帯] MAP             | [黒帯] Life Information   |  建物 or 土地／道路           |
|  地図＋現地マーク        |  周辺施設 10〜11行         |  維持管理（③）               |
|  カーナビ検索住所        |                          |  法令制限・設備・現況・引渡     |
|                      |                          |  備考                      |
+----------------------+--------------------------+---------------------------+
| 帯：ロゴ／社名／免許・協会／住所／URL／TEL・FAX・受付時間／営業社員募集／取引態様＋手数料 |
+-----------------------------------------------------------------------------+
```

- 物件の情報は、右列の **ラベル｜値 の表1本** にまとまっている → テンプレート化しやすい
- 強調は文字サイズと枠だけ（価格・間取りを特大にする）。色はロゴと写真だけ
- 訴求は ◆／☆ の箇条 4〜5本（10〜16字＋補足行）と、「解体更地渡しなのですぐ建築できます！」のような図の横の一言

| （特大）            | 区画図＋「済」印    +------------------+                   |
+-------------------+                  | 特長ラベル 3〜9個（黒地白抜き）          |

- 物件の情報は、下部の **「物件概要」段落**（●所在地／… ●交通／… と羅列）に集約。規約の必要表示を一か所で満たす作り

- 新築は「1ページ＝1棟」。区画図で他の棟に「済」を押し、概要に「販売棟数／全N棟 今回販売棟数／1棟」と書く

### 5件共通の骨組み

型が違っても、載っているブロックは同じ8つ。テンプレートはこの8ブロックを単位にする。

| ブロック | 中身 | A での場所 | B での場所 |
|---|---|---|---|
| 1. 物件の顔 | 種別・物件名/シリーズ名・所在エリア | 右表の先頭／左上見出し | 左上ロゴ枠 |
| 2. 価格と要約 | 販売価格・間取り・主要面積 | 右表の上部（特大） | Room Plan ブロック |
| 3. 交通 | 路線・駅・徒歩分（距離） | 右表 | Access（特大） |
| 4. 図 | 間取り図／区画図（寸法・方位） | 中央上 | 中央〜右 |
| 5. 写真 | 外観写真・パース・内観 | 左上（③） | 上段 |
| 6. 訴求 | キャッチ・ポイント・特長・設備 | ◆☆箇条 | キャッチ＋ラベル＋アイコン |
| 7. 周辺 | 地図＋カーナビ住所＋Life Information | 左下＋中央下 | 左列 |
| 8. 物件スペック | 法令・権利・設備・管理など | 右表 | 物件概要の段落 |

## 5. テンプレート設計に効く気づき

1. **販売図面は業者間で流す資料（マイソク）として作られている。** 帯の「手数料 3%(税込)／分かれ」は、客付け業者への報酬条件。「※広告厳禁※」（③⑤）は、受け取った業者向けの注意書き。取引態様と手数料は、別々の入力項目にする（売主なのに手数料があるのは誤りではない）。
2. **規約上必須の表示が5件とも欠けている。** 情報公開日と次回更新予定日（ネット広告のとき）、取引条件の有効期限（チラシのとき）、私道負担。テンプレートでは「用途（業者間／ネット掲載／チラシ）」を選び、それに応じて必須欄を切り替える。
3. **型Aは項目の表1本、型Bは概要の段落。** 入力項目を1つに揃えれば、どちらの見た目にも差し込める。規約の必要表示は、型Bの物件概要の段落の形で並べると漏れを確認しやすい。
4. **自由文に埋もれた項目がある。** 所在階（③キャッチ内）、その他の月額費用（②③）、高度地区（①その他制限内）。独立した欄に切り出すと、AI が抜けを質問しやすい。
5. **選び忘れ・書き忘れが起きている。** 「完成予定／完成済」が両方残っている（①）。号棟名がない（④）。選択式にして、未選択なら止める。
6. **会社情報の帯は完全に固定。** 案件ごとの手入力をなくせる最初の部分。
7. **画像は5種類。** 外観写真/パース、内観写真、間取り図、区画図、地図。テンプレートは画像の枠と差し替えを受け持ち、画像そのものは作らない（パースは Blender／提案資料側の仕事）。
