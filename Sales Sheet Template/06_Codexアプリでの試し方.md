# Codex アプリで販売図面づくりを試す手順（Mac）

zip をダウンロードするところから、ラフの PDF が出るまで。所要 15 分ほど。

## 1. ファイルを用意する（最初の1回だけ）

1. ブラウザで https://github.com/jny4kgr/landstyle を開き、緑の **Code** → **Download ZIP**
2. ダウンロードした zip をダブルクリックで展開し、できた `landstyle-main` フォルダを `書類` に移す
3. **ターミナル**（Launchpad → その他 → ターミナル）を開き、次を1行ずつ貼って Enter

```bash
cd ~/Documents/landstyle-main/"Sales Sheet Template"/prototype
```
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

   `Successfully installed …` と出れば完了（数分かかる）。`python3` が無いと言われたら https://www.python.org/downloads/ の Python を入れてからやり直す
4. **Google Chrome** が入っていることを確認する（PDF を作るのに使う）

## 2. 物件フォルダを作る（物件ごと）

1. `書類` に `販売図面` フォルダを作り、その中に `20260921_所沢東新井町3号棟` のように **日付_物件名** のフォルダを作る
2. その中に `資料` フォルダを作り、設計図書の PDF（仕様書・実行図・電気図・パース・確認済証など）を入れる

## 3. Codex アプリで始める

1. Codex アプリを開き、**プロジェクトを開く**で `書類 › landstyle-main › Sales Sheet Template` を選ぶ
2. 次の文を貼って送る（物件フォルダ名は自分のものに直す）

> このフォルダの AGENTS.md の手順で、販売図面を作ってください。物件フォルダは ~/Documents/販売図面/20260921_所沢東新井町3号棟 で、資料は「資料」フォルダに入れてあります。所沢市東新井町の新築分譲住宅・全3棟のうち3号棟（他の2棟は売れました）です。Python は prototype/.venv/bin/python を使ってください。地図の取得（make_map.py）と PDF 化（Chrome）はサンドボックスの中では動かないので、その2つは承認を求めてサンドボックスの外で実行してください。まずラフを出して、足りない情報を1問ずつ質問してください。

3. Codex が **「サンドボックスの外で実行してよいか」** と聞いてきたら **承認**する（地図の取得と PDF 化の2回）。拒否すると PDF ができない
4. 質問（価格・地番・私道負担・有効期限・引渡し時期・駅までの距離など）に1つずつ答える。分からない項目は「仮で ◯◯」と答えてよい
5. 文章の候補が番号つきで出たら、番号で選ぶ
6. 「仕上げて」と送ると `物件フォルダ/out/<日付>/naka.pdf`（中面）と `cover.pdf`（表紙）ができる

## 4. 見るところ

- Codex が資料に無い値を推測で埋めていないか（分からないことは質問してくるのが正しい）
- 間取り図の室名・帖数が設計図と合っているか
- できた PDF を、手元の外注の販売図面と並べて見比べる

うまくいかないときは、Codex の画面の文をそのままコピーして小暮に送る。
