# 販売図面づくりの使い方（試作版）

外注していた販売図面（中面）を、AI と会話しながら社内で作るための手順です。いまは試作の段階です。表紙・地図・区画図は、まだ従来どおりの用意が必要です。

## できること

- 設計図（CAD の PDF）から、部屋を色分けした間取り図を作る
- 物件の情報から、中面を B4 横1枚の PDF にする
- 足りない情報を、AI が1問ずつ質問する
- キャッチコピー・特長ラベル・間取りのコメントを、AI が物件の事実から候補として出す（営業が選ぶ）
- 規約で必要な項目の抜け、使ってはいけない言葉、数字の食い違いを自動で点検する

## 最初に1回だけ行う準備

1. Google Chrome が入っていることを確認する（PDF を作るのに使います）
2. Codex に次のように頼む
   > 「Sales Sheet Template/prototype/requirements.txt の内容を、販売図面用の Python 環境に入れてください」

## 物件ごとの流れ

Codex を `Sales Sheet Template` フォルダで開き、次の順に話しかけます。AI の作業内容は同じフォルダの `AGENTS.md` に書いてあります。

| 段階 | 営業がすること | 話しかける例 |
|---|---|---|
| 1. 材料を渡す | 設計図一式・確認済証・パースなどの PDF を物件フォルダの「資料」に入れる | 「◯◯市◯◯の新築の販売図面を作りたい。資料は ~/販売図面/0918_◯◯/資料 に入れた」 |
| 2. ラフを見る | AI が出したラフ PDF を見る。赤い枠が「足りない情報」 | 「ラフを出して」 |
| 3. 質問に答える | AI の質問に1つずつ答える（道路距離・私道負担・引渡し時期など） | そのまま答える |
| 4. 文章を選ぶ | キャッチ・特長ラベル・コメントの候補から番号で選ぶ。直したい言葉があれば伝える | 「キャッチは2番、ラベルは1・3・5・7番」 |
| 5. 仕上げ | 完成した PDF の数字・間取り・文章を確認する | 「仕上げて」 |

価格が変わったときは「価格を◯◯万円に変えて出し直して」と頼むと、新しい日付の版ができます。前の版も残ります。

## 注意

- AI は資料に書いてあることと、営業が答えたことしか使いません。分からないことは質問してきます
- 最後の確認は必ず人が行ってください。特に価格・面積・号棟・間取りの帖数
- 物件の資料は会社の PC の物件フォルダに置き、インターネット上の共有フォルダやこのリポジトリには入れないでください

## いまの限界

- 設計図がスキャン画像しかない物件は、間取り図を自動で作れません（CAD の PDF が必要です）
- 表紙、地図、区画図、設備アイコン、家具のイラストはまだ作れません
- 施工会社によって図面の描き方が違うため、新しい施工会社の図面では調整が必要になることがあります
