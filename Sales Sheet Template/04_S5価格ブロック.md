# S5 価格ブロック（Room Plan／区画価格／参考プラン）

2026-09-15 作成。中面で最も目立つブロック。値は [03_S13物件概要_項目定義.md](03_S13物件概要_項目定義.md) の棟（B）・区画（L）の項目を参照し、ここでは**何をどの順にどう表示するか**と、**表示前の点検**を決める。

- 見本: ①所沢③号棟（2026-09）、④浜崎（2026-07）、所沢12月版（1号棟＋2・3号区）

| 種類 | 出す条件 | 見本 |

## 2. A. Room Plan

### 表示要素（上から）

| # | 要素 | 値（03の項目） | 表記 | 見本 |
|---|---|---|---|---|
| A1 | 号棟 | B01 | `1号棟` | 所沢12月版・①（④はなし → 必須にする） |
| A2 | 見出し | 固定 | `Room Plan`（左右に黒三角の飾り） | ①④所沢 |
| A3 | サブコピー | S3 で生成（任意） | `〜ウッドデッキ採用〜`（赤・10〜15字） | ④「〜採光豊かな3バルコニー〜」 |
| A4 | 販売価格 | B02 | ラベル `販売価格`（小・2行）＋数字（特大）＋`〈税込〉`＋`万円` | `3,980〈税込〉万円` |
| A5 | 間取り | B03 | `3(4)LDK+2バルコニー+ウッドデッキ` | |
| A6 | 土地面積 | B04 | `土地面積／110.56㎡(33.44坪)` | |
| A7 | 建物面積 | B05 | `建物面積／120.47㎡(36.44坪)` ＋ 車庫があれば `※車庫部分21.11㎡含む` | ④ |

| A9 | 特長ラベル | S8（任意・3個まで） | 黒地白抜き | ④「LDK17.0帖」ほか |

- ラベルと値の区切りは `／` に統一する（所沢は `／`、④は `：`。物件概要の `●項目／値` と揃える）
- 数字は半角（自社 Excel は全角だったが、完成版は半角）

### 間取りの書き方

`[可変型]{居室数}[(可変後の居室数)]{LDK|DK|K}[+S][+{N}バルコニー][+ウッドデッキ][+ガレージ]`

| 見本 | 読み方 |
|---|---|
| `3(4)LDK+2バルコニー` | 3LDK。間仕切りを足すと4LDK |
| `可変型3LDK+S+3バルコニー` | 3LDK＋納戸（サービスルーム）＋バルコニー3か所 |
| `3(4)LDK+2バルコニー+ウッドデッキ` | |

- **S（サービスルーム・納戸）**: 採光や換気が建築基準法の居室の基準を満たさない部屋は、居室に数えず「納戸」等と表示する（規約施行規則）。実行図で居室か納戸かを確かめ、居室数に入れない
- 可変の表記（`3(4)` か `可変型`）は物件で揺れている → `3(4)LDK` に統一し、可変の説明は S6 の引出しコメントに回す（案。要相談）

| # | 要素 | 値 | 表記 |
|---|---|---|---|
| C1 | 見出し | L01 | `2号区 Reference Plan`（**所沢は "Referrence" と誤記**） |
| C2 | 参考建物価格 | L07 | `参考建物価格 2,000〈税込〉万円` |
| C3 | 建物面積 | L08 | `建物面積／86.94㎡(26.29坪)` |
| C4 | 土地＋参考建物価格 | L09＝L02＋L07（計算） | `土地+参考建物価格 4,090〈税込〉万円` |

- C4 に〈税込〉を付けるなら、土地価格は非課税・建物価格は税込である旨が伝わるようにする（所沢は合計に〈税込〉を付けている。表記の正確さは要確認）

## 5. 表示前の点検（スクリプトで行う）

| # | 点検 | NG のとき |
|---|---|---|
| K1 | 販売中の棟に価格（B02）がある | 止める（「価格未定」での配布は予告広告の扱いになる。今回は対象外） |
| K2 | 新築の価格に〈税込〉が付く | 自動で付ける |
| K3 | 坪 ＝ ㎡ × 0.3025 を小数第2位で切り捨て | 再計算した値で上書き |
| K4 | 未完成の棟に建築確認番号（B07）がある | 止める（確認前は広告できない。規約第5条） |
| K5 | 土地＋参考建物価格 ＝ 土地価格＋参考建物価格 | 計算値で上書き（手入力させない） |
| K6 | 間取りの居室数・LDK が、S6 間取り図の室名と合う | 警告して営業に確認 |
| K7 | 車庫がある棟で、建物面積に車庫を含むかの注記がある | 逆質問 |
| K8 | 英字見出しのつづり（Reference／Service room など）が辞書と一致 | 辞書の表記に直す |
| K9 | 参考プランがあるとき、C6 の注記と L10 がある | 止める |
| K10 | 物件概要（S13）の「別記」が、このブロックの値で全部埋まっている | 止める |

## 6. 逆質問

| 条件 | 質問 |
|---|---|
| 号棟が空 | 「この棟は何号棟ですか？」 |
| 価格が空 | 「◯号棟の販売価格（税込）を教えてください」 |
| 面積が資料ごとに違う | 「延床面積に 120.47㎡ と 99.36㎡（容積率対象）があります。広告に出すのは延床の 120.47㎡ でよいですか？」 |
| 車庫・ガレージがある | 「建物面積に車庫部分は含まれますか？含む場合は車庫の面積を教えてください」 |
| 納戸と思われる部屋がある | 「◯◯（6.0帖）は、居室の採光基準を満たしていますか？満たさなければ S（サービスルーム）と表示します」 |
| 参考プランがある | 「参考建物価格のほかに必要な費用（地盤改良・給排水引込・設計料など）と金額を教えてください」 |
